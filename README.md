# Aplikacja internetowa do rezerwacji biletów w kinie
## Opis
Aplikacja internetowa oferująca przeglądanie repertuaru kinowego i rezerwację miejsc. Program obsługuje również takie funkcjonalności jak wybór siedzeń czy wybór rodzaju biletu.

Aplikacja wykorzystuje następujące technologie:
- [JavaScript]
- [React]
- [Node.js]
- [Express]
- [HTML]
- [CSS]
- [Bulma]
- [PostgreSQL]
- [SQL]
